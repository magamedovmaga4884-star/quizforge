# QuizForge 🎓

**QuizForge** — современная, простая, стабильная и полностью рабочая веб-система для создания и проведения учебных тестов в институте.

Система включает отдельные роли для **Преподавателя** и **Студента**, поддерживает создание тестов вручную и интеллектуальную генерацию заданий из методических материалов (PDF, DOCX, PPTX, TXT) с помощью **локальной нейросети через Ollama** — без использования платных API и без отправки конфиденциальных учебных данных во внешние облака.

---

## 1. Что такое QuizForge

* **Для преподавателя:**
  * Удобное создание и организация дисциплин / предметов.
  * Создание тестов с ручным добавлением вопросов или автогенерацией через локальный AI.
  * Поддержка типов заданий: *Один правильный*, *Несколько правильных*, *Да / Нет (True / False)*.
  * Загрузка учебных файлов (PDF, Word DOCX, PowerPoint PPTX, текстовые файлы TXT) с автоматическим извлечением текста.
  * Публикация теста с генерацией короткого 6-значного кода комнаты (например, `A7K9P2`).
  * Полная статистика прохождения, аналитика правильности ответов по каждому вопросу.
  * Дублирование существующих тестов в один клик.

* **Для студента:**
  * Мгновенный вход по коду комнаты без сложных меню.
  * Прохождение теста по одному вопросу за раз с индикатором прогресса.
  * Серверный таймер обратного отсчета с автоматической отправкой при истечении времени.
  * Мгновенная автоматическая проверка и отображение набранных баллов и процентов.
  * Личная история пройденных тестирований.

## 2. Требования

* **Docker & Docker Compose** (Docker Desktop на Windows/Mac или docker-ce на Linux).
* **Ollama** (установленная локально на хост-машине для работы функции AI-генерации).
* Опционально для запуска без Docker: **Python 3.12+**, **Node.js 18+**, **PostgreSQL 14+**.

---

## 3. Установка

Клонируйте репозиторий или перейдите в папку проекта:

```bash
cd quiz
```

Скопируйте файл конфигурации окружения:

```bash
cp .env.example .env
```

---

## 4. Запуск PostgreSQL и проекта через Docker Compose

Самый простой способ запустить всю систему целиком (база данных PostgreSQL, backend FastAPI и frontend Next.js):

```bash
docker compose up --build
```

После завершения сборки и запуска доступны следующие сервисы:

* **Frontend (веб-интерфейс):** [http://localhost:3000](http://localhost:3000)
* **Backend API:** [http://localhost:8000](http://localhost:8000)
* **Интерактивная документация Swagger (OpenAPI):** [http://localhost:8000/docs](http://localhost:8000/docs)
* **PostgreSQL:** `localhost:5432` (пользователь: `postgres`, пароль: `postgrespassword`, база: `quizforge`)

---

## 5. Запуск Ollama

Ollama запускается непосредственно на хостовой машине (не внутри контейнера), что обеспечивает максимальную производительность с использованием вашей видеокарты (GPU) или процессора.

1. Скачайте и установите Ollama с официального сайта: [https://ollama.com/download](https://ollama.com/download)
2. Убедитесь, что служба Ollama запущена:
   ```bash
   ollama --version
   ```
3. Сервис будет доступен по адресу `http://localhost:11434`.

---

## 6. Установка AI-модели

Для генерации вопросов рекомендуется использовать качественную и быструю локальную модель, например `gemma3:4b`, `llama3.2` или `qwen2.5:7b`:

```bash
ollama run gemma3:4b
```

Проверить список загруженных моделей:

```bash
ollama list
```

Если вы хотите использовать другую модель, просто укажите её в файле `.env` или `docker-compose.yml`:

```env
OLLAMA_MODEL=gemma3:4b
```

> **Важно:** если Ollama или модель временно недоступны, система QuizForge **не падает**, а показывает понятное предупреждение в интерфейсе. Преподаватель всегда может продолжать создавать и редактировать вопросы вручную.

## 7. Инициализация начальных данных (Seed)

Чтобы наполнить базу данных базовыми предметами (Математика, Программирование, История, Физика, Информатика) и демонстрационными аккаунтами:

**В Docker:**
```bash
docker compose exec backend python -m app.seed
```

**Локально:**
```bash
python -m app.seed
```

После выполнения команды будут созданы:
* Предметы: *Программирование*, *Математика*, *История*, *Информатика*, *Физика*.
* Демо-преподаватель: `teacher@quizforge.edu` / `teacher123`
* Демо-студент: `student@quizforge.edu` / `student123`

## 8. Создание пользователя

1. Откройте [http://localhost:3000/register](http://localhost:3000/register).
2. Выберите роль:
   * **Преподаватель** — для создания тестов и просмотра статистики.
   * **Студент** — для ввода кода комнаты и сдачи тестов.
3. Заполните ФИО, Email и пароль.
4. Нажмите «Зарегистрироваться» — вход выполнится автоматически.

---

## 9. Создание первого теста

1. Войдите как преподаватель и перейдите в раздел **«Создать тест»** (`/tests/create`).
2. **Шаг 1:** Введите название теста, выберите предмет и укажите тему.
3. **Шаг 2:** Задайте количество вопросов, уровень сложности и лимит времени (в минутах).
4. Загрузите учебный материал (PDF, DOCX, PPTX или TXT) в блок Drag & Drop.
5. Нажмите **«Сгенерировать тест через AI»** (или **«Создать вручную»**).
6. В открывшемся редакторе (`/tests/[id]/edit`):
   * Просмотрите вопросы и варианты ответов.
   * Отредактируйте формулировки или добавьте свои вопросы при необходимости.
   * Нажмите **«Опубликовать тест»**.
7. Система сгенерирует уникальный 6-значный **код комнаты** (например, `A7K9P2`) и предложит скопировать его.

---

## 10. Как студент проходит тест

1. Студент переходит на главную страницу [http://localhost:3000](http://localhost:3000) или в кабинет [http://localhost:3000/student](http://localhost:3000/student).
2. Вводит код комнаты (например: `A7K9P2`) и нажимает «Начать тест».
3. На странице лобби знакомится с регламентом и запускает тестирование.
4. В процессе тестирования:
   * Вопросы отображаются по одному.
   * Таймер вверху страницы отсчитывает оставшееся время.
   * Выбранные ответы мгновенно фиксируются на сервере.
5. По завершении (или по истечении таймера) студент видит:
   * Итоговый балл и процент верных ответов.
   * Количество правильных и ошибочных решений.
   * Затраченное время.

Преподаватель в реальном времени видит результаты на странице **«Результаты»** (`/tests/[id]/results`), включая поимённый список студентов и диаграмму точности по каждому вопросу.

## 11. Документация API (Swagger / OpenAPI)

FastAPI автоматически формирует интерактивную документацию Swagger UI:
* **Swagger UI:** [http://localhost:8000/docs](http://localhost:8000/docs)
* **ReDoc:** [http://localhost:8000/redoc](http://localhost:8000/redoc)

Основные эндпоинты:
* `POST /api/auth/register` — регистрация
* `POST /api/auth/login` — вход и получение JWT токена
* `GET  /api/auth/me` — профиль текущего пользователя
* `GET  /api/subjects` — список предметов
* `POST /api/subjects` — создание предмета
* `GET  /api/tests` — список тестов преподавателя
* `POST /api/tests` — создание теста
* `POST /api/tests/{id}/materials` — загрузка PDF/DOCX/PPTX/TXT
* `POST /api/tests/{id}/generate` — вызов локального AI
* `POST /api/tests/{id}/publish` — публикация теста и генерация кода
* `POST /api/rooms/{code}/join` — проверка кода комнаты студентом
* `POST /api/tests/{id}/attempts` — начало попытки тестирования
* `GET  /api/attempts/{id}` — состояние теста с таймером
* `POST /api/attempts/{id}/answer` — сохранение ответа
* `POST /api/attempts/{id}/finish` — завершение и оценивание
* `GET  /api/tests/{id}/results` — результаты группы для преподавателя
* `GET  /api/tests/{id}/statistics` — статистика ответов по вопросам

## 13. Troubleshooting (Устранение неполадок)

* **«Локальный AI сейчас недоступен»:**
  * Убедитесь, что Ollama запущена на хост-машине: выполните `ollama list` в терминале.
  * Если Docker запущен на Windows/Mac, связь с хостом осуществляется через `http://host.docker.internal:11434`.
  * Проверьте, загружена ли модель: `ollama run gemma3:4b`.
  * Вы всегда можете нажать **«Создать вручную»** и составить тест без участия AI.

* **Порт 5432 или 8000 уже занят:**
  * Если на вашей машине уже работает локальный PostgreSQL, измените порт в `docker-compose.yml`, например `"5433:5432"`.

* **Студент видит «Время вышло»:**
  * Сервер отслеживает время с момента старта попытки на основе системных часов сервера. Если студент закрыл вкладку и вернулся позже лимита времени, тест завершается автоматически с сохранением уже данных ответов.
